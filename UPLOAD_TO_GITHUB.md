# Что делать после скачивания

1. Распакуйте архив.
2. Откройте на ноутбуке:
   `https://github.com/digitalwaveai/ai-agency`
3. Нажмите **Add file → Upload files**.
4. Перетащите все файлы и папки из распакованной папки.
5. Внизу нажмите **Commit changes**.
6. Перейдите в Railway — новый deployment должен начаться автоматически.
7. Когда статус станет **Active**, откройте Telegram и отправьте боту:

```text
/status
```

Если deployment станет красным, откройте его и пришлите последние строки
**Build Logs** или **Deploy Logs**. Значения ключей на скриншоте должны быть
скрыты.
